# School Management System
PHP + MySQL + HTML/CSS/JS. Runs on XAMPP.
1. Copy this folder into `C:\xampp\htdocs\`.
2. Start Apache and MySQL in the XAMPP Control Panel.
3. Open http://localhost/school-management-system/install.php (once).
4. Open http://localhost/school-management-system/ and sign in: admin / Admin@123 (also teacher1 / Teacher@123, accounts1 / Accounts@123, library1 / Library@123).
Edit school name, year, fine per day and loan days at the top of `inc.php`; colours and fonts at the top of `style.css`.
